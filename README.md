# 贪吃蛇（pygame 图形窗口）

当前验收修改：初始菜单提供开始游戏、帮助、退出；帮助页有三张可切换教程卡片。游戏使用右侧 220×220 鼠标摇杆框或 WASD 转向，速度为 189 px/s，蛇与食物的面积按上一版缩至约 2/3。初始有 3 个食物，吃掉后补充，最多 10 个。单击游戏区暂停，双击空格暂停；Esc 在游戏内返回主页面，主页面 Esc 退出。

按照 `docs/userdocs/require.txt` 和用户验收反馈逐步实现。步骤 1 已验收；本轮修改等待用户验收。

蛇持续前进，按住 WASD 或移动右侧鼠标摇杆平滑转向，松开后沿当前角度继续前进。
蛇与食物的面积按用户确认缩小到上一版的 **2/3**，所以线性尺寸乘以 `sqrt(2/3)`。

## 本次修改

| 验收反馈 | 当前行为 |
| --- | --- |
| 没碰到墙就失败 | 按蛇头圆周求首次接触位置，结束画面中的蛇头贴住墙体 |
| 食物与蛇位置错位 | 食物使用独立的连续中心坐标；圆碰到方块的边或角即可吃到 |
| WASD 像摇杆一样转向 | 按住对应方向逐渐改变航向，组合键支持斜向施力，松开保持当前任意角度 |
| 身体需要沿曲线运动 | 保存蛇头走过的路径，身体按路径长度逐节跟随 |
| 虚拟摇杆 | 右侧 220×220 像素框；WASD 或鼠标输入偏移，整体 40% 透明 |
| 前进和转弯流畅 | 目标 120 FPS，物理使用 240 Hz 小步积分，绘制保留小数位置 |
| 蛇和食物面积缩至上一版的 2/3 | 蛇直径约 29.4 像素，食物边长约 14.7 像素 |

前进速度为 **189 像素/秒**，是上一版的 1.5 倍。开局生成 3 个食物，吃掉后补充，场上最多 10 个。
转弯不会改变前进速度；接近摇杆方向时转动逐渐放缓，反向按键通过弧线完成掉头。
屏幕实际显示帧率取决于显示器和运行环境。

## 运行

需要 Windows 11 或 Ubuntu 22.04、图形桌面、Python 3.10+ 和 `pygame-ce>=2.5.8`。
本次验证环境为 Python 3.10.12 / pygame-ce 2.5.8。

Ubuntu 首次运行前准备虚拟环境工具和中文字体：

```bash
sudo apt update
sudo apt install -y python3-venv fonts-noto-cjk
bash scripts/run.sh
```

启动脚本首次运行会创建项目内 `.venv` 并安装依赖，后续启动会复用该环境。
也可在项目根目录手动启动：

```bash
PYTHONPATH=src .venv/bin/python -m greedy_snake
```

Windows：

```powershell
python -m pip install -r requirements.txt
.\scripts\run.cmd
```

## 操作

| 操作 | 作用 |
| --- | --- |
| 主页面“开始游戏” / Enter | 开始游戏 |
| 主页面“帮助” | 查看操作、得分和失败条件图示，可用左右三角翻页 |
| 主页面“退出” / Esc | 退出程序 |
| 按住 W / A / S / D | 向上 / 左 / 下 / 右施加转向，大小写均可 |
| 鼠标移入右侧摇杆框 / 按住拖动 | 以鼠标位置控制摇杆；移出或松开回中 |
| 同时按相邻两个方向键 | 向斜向施加转向；相反按键互相抵消 |
| 松开 WASD | 摇杆回中，蛇沿松开瞬间的方向持续前进 |
| 游戏画面单击 / 连按两次空格 | 暂停 |
| 暂停后单击 / 连按两次空格 | 继续 |
| 暂停后 R / 右侧环形箭头 | 重试 |
| 暂停后左侧退出图标 / Esc | 返回主页面 |
| 结束后 R / 单击 | 重试 |
| 游戏中 Esc / Q | 返回主页面 |
| 主页面 Esc / Q | 退出程序 |
| 1 / 2 / 3 / 4 | 预览：游戏 / 主页面 / 暂停 / 结束 |

每吃一个食物增长一节、加 1 分。蛇头碰墙或碰到非相邻身体后结束，保留碰撞位置、食物和分数。
相邻颈部原本就与蛇头重叠连接，不计作自撞。暂停不积累运动时间；窗口失去焦点时清除方向输入，防止按键卡住。

## 步骤 2 验收

1. 任意键开始后观察持续、平滑前进，短按 W 后松开，蛇应沿中间角度继续直行。
2. 长按方向键、组合按键或按反向键，确认转弯为连续弧线，身体沿原轨迹跟随。
3. 按住 WASD 时摇杆偏移，松开立即回中；摇杆整体透明度为 40%。
4. 对比蛇和食物尺寸：蛇直径约 29.4 像素、食物边长约 14.7 像素；场上食物最多 10 个。
5. 朝墙前进直到失败，确认头部外围真正贴墙；斜着靠近食物边缘也应能正常吃到。
6. 吃食物后确认增长一节、分数加一；绕回身体应在圆周接触时失败。
7. 暂停、释放方向键再继续，确认蛇不会突然跳跃或继续受到已经松开的按键影响。

## 尺寸

窗口 1200×720，棋盘外框 1152×600，可活动区域 1128×576。

| 元素 | 尺寸 / 外观 |
| --- | --- |
| 蛇头 / 蛇身 | 直径约 29.4 像素的蓝色 / 黄色实心圆 |
| 相邻身体 | 沿轨迹相距约 25.7 像素，重叠颜色加深 |
| 食物 | 边长约 14.7 像素的绿色空心正方形，边框 2 像素；最多同时 10 个 |
| 墙体 | 灰色实心边框，厚 12 像素 |
| 虚拟摇杆 | 右侧 220×220 像素区域，40% 透明 |
| 暂停面板 | 400×168 像素，70% 透明 |
| 结束界面 | 保留接触时画面，遮罩和面板 70% 透明 |

- `test/`：自动化测试。
- `docs/userdocs/`：用户需求与对话记录。
