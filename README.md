# 贪吃蛇（pygame 图形窗口）

当前验收版本：头碰到自己身体不会失败；蛇最长 50 节，达到上限后吃食物只计分；按住 Shift 可用能量加速。主页面右上角设置图标可切换 WASD 或鼠标摇杆模式。摇杆模式检测整个窗口中的鼠标位置，不需要按住，右下角显示虚拟摇杆。

按照 `docs/userdocs/require.txt` 和用户验收反馈逐步实现。步骤 1 已验收；本轮修改等待用户验收。

蛇持续前进，按住 WASD 或移动右侧鼠标摇杆平滑转向，松开后沿当前角度继续前进。
蛇与食物的面积按用户确认缩小到上一版的 **2/3**，所以线性尺寸乘以 `sqrt(2/3)`。

## 本次修改

| 验收反馈 | 当前行为 |
| --- | --- |
| 没碰到墙就失败 | 按蛇头圆周求首次接触位置，结束画面中的蛇头贴住墙体 |
| 食物与蛇位置错位 | 食物使用独立的连续中心坐标；圆碰到方块的边或角即可吃到 |
| WASD 像摇杆一样转向 | 按住对应方向逐渐改变航向，组合键支持斜向施力，松开保持当前任意角度 |
| 身体需要沿曲线运动 | 保存蛇头走过的路径，身体按路径长度逐节跟随 |
| 虚拟摇杆 | 摇杆模式显示在右下角，整个窗口的鼠标位置均可控制，整体 40% 透明 |
| 前进和转弯流畅 | 目标 120 FPS，物理使用 240 Hz 小步积分，绘制保留小数位置 |
| 蛇和食物面积缩至上一版的 2/3 | 蛇直径约 29.4 像素，食物边长约 14.7 像素 |
| 自身碰撞 | 头碰到自己身体不会失败，只有墙体会结束游戏 |
| 长度上限 | 蛇头与身体节点总数最多 50，达到后食物只计分 |
| Shift 加速 | 速度提高到 1.5 倍，能量耗尽后自动恢复普通速度 |
| 能量 | 每个食物恢复 1/15，每秒自然恢复 1/30，加速每秒消耗 1/6 |

普通前进速度为 **189 像素/秒**；按住 Shift 时为 1.5 倍。开局生成 3 个食物，吃掉后补充，场上最多 10 个。
转弯不会改变前进速度；接近摇杆方向时转动逐渐放缓，反向按键通过弧线完成掉头。
屏幕实际显示帧率取决于显示器和运行环境。

## 运行

需要 Windows 11 或 Ubuntu 22.04、图形桌面、Python 3.10+ 和 `pygame-ce>=2.5.8`。
本次验证环境为 Python 3.10.12 / pygame-ce 2.5.8。

Ubuntu 首次运行前准备虚拟环境工具和中文字体：

```bash
sudo apt update
sudo apt install -y python3-venv fonts-noto-cjk
bash scripts/run.sh
```

启动脚本首次运行会创建项目内 `.venv` 并安装依赖，后续启动会复用该环境。
也可在项目根目录手动启动：

```bash
PYTHONPATH=src .venv/bin/python -m greedy_snake
```

Windows：

```powershell
python -m pip install -r requirements.txt
.\scripts\run.cmd
```

## 操作

| 操作 | 作用 |
| --- | --- |
| 主页面“开始游戏” / Enter | 开始游戏 |
| 主页面“帮助” | 查看操作、能量、得分和失败条件图示，可用左右三角翻页 |
| 主页面“退出” / Esc | 退出程序 |
| 主页面右上角设置图标 | 切换 WASD 或鼠标摇杆模式 |
| WASD 模式：按住 W / A / S / D | 向上 / 左 / 下 / 右施加转向，大小写均可 |
| 摇杆模式：移动鼠标 | 鼠标在整个窗口中的位置都参与方向计算，不需要按住 |
| 同时按相邻两个方向键 | 向斜向施加转向；相反按键互相抵消 |
| 松开 WASD | 摇杆回中，蛇沿松开瞬间的方向持续前进 |
| 按住 Shift | 消耗能量加速，能量耗尽后停止加速 |
| 游戏画面单击 / 连按两次空格 | 暂停 |
| 暂停后单击 / 连按两次空格 | 继续 |
| 暂停后 R / 右侧环形箭头 | 重试 |
| 暂停后左侧退出图标 / Esc | 返回主页面 |
| 结束后 R / 单击 | 重试 |
| 游戏中 Esc / Q | 返回主页面 |
| 主页面 Esc / Q | 退出程序 |
| 1 / 2 / 3 / 4 | 预览：游戏 / 主页面 / 暂停 / 结束 |

每吃一个食物加 1 分并恢复 1/15 能量；不足 50 节时同时增长一节。蛇只有碰到墙时结束。暂停不积累运动时间，也不会消耗或恢复能量；窗口失去焦点时清除方向输入，防止按键卡住。

能量是 0~1 的连续浮点值。自然恢复和 Shift 消耗分别计算后合并，并按 240 Hz 物理小步更新；能量条使用小数填充高度和平滑缩放，不按秒跳到新值。相关参数为：

| 来源 | 每秒变化 |
| --- | --- |
| 自然恢复 | +1/30 |
| Shift 消耗 | -1/6 |
| 普通状态合计 | +1/30 |
| 加速状态合计 | +1/30 - 1/6 |
| 吃到一个食物 | 额外 +1/15 |

## 本轮验收

1. 让蛇头穿过或贴住自己的非相邻身体，确认游戏不会结束。
2. 吃到 50 节后继续吃食物，确认长度不再增加，但分数和能量仍正常增加。
3. 在能量未满时观察能量条，确认它每帧连续变化；按住 Shift 加速时观察消耗，耗尽后恢复普通速度。
4. 在主页面点击右上角齿轮，分别选择 WASD 和鼠标摇杆。
5. 摇杆模式下不按键，只移动鼠标到窗口任意位置，确认蛇转向，右下角摇杆同步偏移。
6. 在帮助页检查操作与设置、能量、得分、失败条件四页；得分页只显示一个食物和“+1”。
7. 朝墙前进直到失败，确认碰撞仍停在实际圆形外围，并可用 R 重试。

## 尺寸

窗口 1200×720，棋盘外框 1152×600，可活动区域 1128×576。

| 元素 | 尺寸 / 外观 |
| --- | --- |
| 蛇头 / 蛇身 | 直径约 29.4 像素的蓝色 / 黄色实心圆 |
| 相邻身体 | 沿轨迹相距约 25.7 像素，重叠颜色加深 |
| 食物 | 边长约 14.7 像素的绿色空心正方形，边框 2 像素；最多同时 10 个 |
| 墙体 | 灰色实心边框，厚 12 像素 |
| 虚拟摇杆 | 右下角底座半径 72 像素，旋钮半径 22 像素，40% 透明 |
| 能量条 | 右侧竖直条，按小数能量值连续填充 |
| 暂停面板 | 400×168 像素，70% 透明 |
| 结束界面 | 保留接触时画面，遮罩和面板 70% 透明 |

## 目录

- `src/greedy_snake/state.py`：连续运动、轨迹采样、接触计算与食物。
- `src/greedy_snake/app.py`：事件循环、WASD 保持状态、暂停和重试。
- `src/greedy_snake/config.py`：速度、转向响应、尺寸和界面文案。

- `scripts/`：Windows / Ubuntu 启动脚本和截图工具。
- `test/`：自动化测试。
- `docs/userdocs/`：用户需求与对话记录。
